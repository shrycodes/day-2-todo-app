# Day 2 - Todo App 

A responsive Todo App built with HTML, CSS, and JavaScript.

## Features

* Add tasks
* Mark tasks complete
* Delete tasks with animation
* Filter: All / Done / Pending
* Saves tasks using Local Storage
* Press Enter to add tasks

## Tech Used

* HTML
* CSS
* JavaScript

## What I Learned

* DOM Manipulation
* Event Listeners
* localStorage
* Dynamic UI updates
